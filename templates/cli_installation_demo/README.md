# 💻 实战模板：Reasonix CLI 极客安装演示 (CLI Installation Demo)

> 这是一个开箱即用的实战分镜与参数模板，直接用于制作 20~30 秒的高能 CLI 工具发布短视频。

---

## 1. 核心技术元数据
- **项目名称**：`Reasonix CLI`
- **一句话标语**：`Next-Gen AI Reasoning & Task Orchestration Engine`
- **安装命令**：`npm install -g reasonix` (或 `cargo install reasonix-cli`)
- **验证命令**：`reasonix --version`
- **首次运行**：`reasonix init --template fullstack`
