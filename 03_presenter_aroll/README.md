## 🎥 拍摄机位与布光秘籍

### 1. 构图与留白 (三分法)
为了完美留出放置 HyperFrames 3D 浮动终端的空间，拍摄时建议：
- **构图 A（侧边留白）**：身体位于画面左侧或右侧 1/3 处，给另一侧预留至少 `800px ~ 1000px` 的清晰负空间（Negative Space）；
- **构图 B（居中 + 全屏切入）**：人物正中出镜，适合快节奏跳剪，讲到实操时全屏硬切到 B-Roll。

### 2. 气口节奏 (Speech Cadence)
- **短句优先**：单句尽量控制在 8~16 个汉字之间；
- **允许停顿**：说完一句可停顿 1~2 秒再讲下一句，不用紧张，剪映的“删除静音”会在 1 秒内帮你切除所有多余停顿，呈现极致网感。
